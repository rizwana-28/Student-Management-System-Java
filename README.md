# Student-Management-System-Java

## Description
A Java console-based Student Management System that allows users to manage student records through a menu-driven interface. The application supports adding, updating, deleting, and displaying student information.

## Features
- Add new student details (ID, Name, Mobile, Email, Marks)
- Update existing student records
- Delete student records using Student ID
- Display all students
- Display a particular student by ID
- Show total number of students

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Scanner class
- Arrays

## Concepts Applied
- Classes and Objects
- Constructors
- Static variables
- Arrays
- Conditional statements and loops
